# 需求与设计决策树

来自 2026-10-04 的需求拷问会话（grill-with-docs）。分三部分：用户已敲定的需求（原话）、待拍板的分叉（附推荐）、agent 按最佳判断先行的默认。全部拍板后，本文件就是需求基线，开发按里程碑推进。

## 已敲定（用户原话，2026-10-04）

- 一个**多标签页评测工作台**，以「评测」为主、「编码」为辅，用来对比不同图片编码格式的画质和压缩效率。
- 每个标签页是一个独立的**跑分组**，互不干扰；可新建、关闭、重命名，可单独命名（如「人像测试」「风景测试」）。
- 每个跑分组内部三块：**图片对比查看器**（默认就有，核心功能）、**跑分结果区**（表格/排名）、**操作区**（选原图、选跑分图、触发跑分）。
- 对比查看器支持六种模式：**左右分屏**（主力，同步缩放平移）、**滑动对比**（可拖动分割线）、**多视图**（2×2 / 3×3 网格，多图同步缩放平移，每格可独立选图）、**叠加对比**（半透明）、**差异图**（高亮差异区域）、**闪烁切换**（原图/跑分图交替显示）。**明确不做上下分屏**。
- 两种工作模式（每个跑分组可选）：
  - **外部导入模式**：选一张原图作基准，再选若干张已用其他工具压好的跑分图，工具跑分并对比。
  - **一站式模式**：选一张原图，工具自动用多种格式压缩，再自动跑分。
- 最终形态：双击打开一个**桌面原生窗口**就能用，**不要在浏览器里操作**；支持多标签页并行；**CLI** 一行命令批量跑；核心逻辑在 **Windows / Linux / macOS** 三端都能跑。
- 开发环境：WSL 里开发，日常在 Windows 上使用。
- 分工：用户做需求确认与效果验收，技术决策由 agent 负责；关键分叉给选项和建议，用户拍板。

## 待拍板（每题附推荐，回复编号即可）

- **Q1 视频范围**：视频评测（VMAF、BD-rate）进第一版吗？
  ➡️ 推荐：第一版只做图片，视频进路线图，核心库接口预留扩展位。
- **Q2 GUI 技术路线**：Tauri 2 + Rust 核心（推荐，窗口内 Canvas 渲染、核心三端复用、安装包约 15MB）；PySide6 + Python（真原生控件，但打包 150MB、AVIF/JXL 编码是硬伤）；Electron + Node.js（生态最成熟但太重）。
  ➡️ 推荐：Tauri 2 + Rust 核心。三者都是双击打开的桌面窗口，都不用浏览器。
- **Q3 主要图片类型**：照片 / 截图与图形 / 动漫插画 / 混合。
  ➡️ 推荐：照片为主，决定默认格式组合与感知指标侧重。
- **Q4 跑分组边界**：一个跑分组 = 一张原图的评测，还是可攒多张原图的多轮评测？
  ➡️ 推荐：一页一张原图，想测另一张就开新页；底层数据结构预留多轮扩展。
- **Q5 一站式默认编码阶梯**：默认用哪些格式、哪些质量档？
  ➡️ 推荐：JPEG（MozJPEG）/ WebP / AVIF / JPEG-XL × 质量档 60 / 75 / 90，界面可自定义。
- **Q6 开源与许可**：仓库是否开源、用什么许可？
  ➡️ 推荐：开源，MIT。

## agent 按最佳判断先行的默认（反对即改）

- 界面语言：简体中文，术语（SSIM、AVIF 等）保持原文。
- 结果持久化：跑分组（含跑分结果）自动保存到工作区目录，可重新打开；支持导出 CSV / HTML 报告。
- CLI：核心库同一套，先做 `score`（外部导入跑分）与 `run`（一站式批量）两个子命令，输出默认 CSV，可选 JSON / HTML。
- 分发：GitHub Actions 出三平台产物；Windows 提供双击即用的便携 exe + 安装包；初期均不签名（macOS 签名需要付费开发者账号，暂不做）。
- 指标集：PSNR / SSIM / MS-SSIM 基线 + Butteraugli / SSIMULACRA2 感知类；编码细节、编码器版本、项目结构等技术事项由 agent 决定并记入 `docs/decisions.md`。

## 里程碑

- **M0 技术栈落地**：Tauri 骨架在 WSL 里启动一个真实桌面窗口（截图交付）；验证门命令与依赖安装命令实测后回填 `AGENTS.md` 和 README。
- **M1 核心库 + CLI（外部导入跑分）**：解码、指标计算、`score` 子命令输出指标表；用示例图验收。
- **M2 GUI 最小可用**：新建跑分组、选原图/跑分图、触发跑分、左右分屏与滑动对比、结果表格排名。
- **M3 查看器全模式**：多视图 2×2/3×3、叠加、差异图、闪烁切换；同步缩放平移流畅。
- **M4 一站式模式 + 持久化**：编码阶梯自动生成跑分图并跑分；跑分组自动保存/重开；导出报告。
- **M5 三端打包**：GitHub Actions 出 Windows/Linux/macOS 产物，Windows 双击即用。
- **后续**：视频评测（VMAF、BD-rate），按 Q1 拍板结果排期。
